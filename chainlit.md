# AI Financial Analyst — Demo

Read-only ассистент финансового специалиста в личном кабинете компании-партнёра BaaS-платформы.

**Что умеет:**
- Аналитика по транзакциям, картам и payout'ам вашей компании (структурированные данные).
- Поиск по внутренним регламентам, тарифной политике и шаблонам отчётности.
- Сравнение фактов с регламентами («укладываемся в лимит?», «правильно ли начислена комиссия?»).
- Draft-предложения действий: выгрузка отчёта, открытие тикета, подготовка акта, подсветка расхождения. **Сам не исполняет** — только готовит черновик для подтверждения.

**Что не делает:**
- Не движет деньги, не открывает тикеты, не отправляет письма.
- Не показывает данные других компаний — изоляция tenant'ов на уровне SQL guard и Qdrant payload-фильтра.
- Не принимает комплаенс / AML-решения.

**Перед первым вопросом** выберите профиль (компания · роль) — это эмулирует логин в личный кабинет. В production эти параметры приходят из auth-токена и не меняются в рамках сессии. Чтобы сменить идентичность — **New Chat** и выберите другой профиль.
