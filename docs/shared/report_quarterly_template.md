# Шаблон квартальной финансовой отчётности

Документ задаёт структуру стандартного квартального отчёта, который оператор формирует для каждой компании-партнёра и сохраняет в `report_snapshots` с `report_type='quarterly'`.

## Период и сроки формирования

Период покрывает один календарный квартал (Q1 = январь–март, Q2 = апрель–июнь и т. д.). Снэпшот формируется на 5-й рабочий день месяца, следующего за отчётным кварталом, и доступен в личном кабинете партнёра в этот же день.

## Состав отчёта (`payload_json`)

Поля payload, входящие в снэпшот:

- `totals.transactions_amount` — суммарный объём транзакций по картам, в валюте отчёта.
- `totals.transactions_fee` — суммарная комиссия по транзакциям.
- `totals.payouts_amount` — суммарный объём выплат.
- `totals.payouts_fee` — суммарная комиссия по выплатам.
- `breakdown_by_category` — разбивка `transactions_amount` по категориям расходов.
- `breakdown_by_employee` — разбивка по сотрудникам (топ-20 по сумме).
- `anomalies` — список аномалий: операции, превышающие 3σ от среднего, отклонённые тикеты, расхождения комиссий.
- `period_comparison` — сравнение с предыдущим кварталом по ключевым метрикам.

## Валюта отчёта

Базовая валюта отчёта — RUB. При наличии операций в иных валютах суммы конвертируются по курсу ЦБ РФ на дату операции и фиксируются в `payload_json.fx_method='cbr_daily'`.

## Доступ к отчёту

Чтение снэпшота доступно ролям `cfo`, `finance_manager`, `accountant`. Аудитор имеет доступ только к проверочной части (`anomalies` + `period_comparison`). Подробности выгрузки — `report_export_procedure`.

## Версионирование

Шаблон обновляется не чаще одного раза в год. При смене версии прежние снэпшоты остаются в той версии, в которой они были созданы; новая версия применяется только к будущим снэпшотам. Текущая версия шаблона указана в этом документе и в поле `payload_json.template_version`.
