# Регламент выгрузки отчётов и закрывающих документов

Документ описывает порядок выгрузки отчётов и закрывающих документов из личного кабинета компании-партнёра.

## Что можно выгрузить

В выгрузке доступны:

- Квартальные и годовые снэпшоты (`report_snapshots`), см. шаблоны `report_quarterly_template` и `report_annual_template`.
- Реестр транзакций по картам за произвольный период.
- Реестр выплат за произвольный период.
- Закрывающие документы по комиссиям оператора: акты выполненных работ, счета-фактуры, УПД.
- Сводный отчёт по аудит-логу для роли `auditor`.

## Форматы

- Снэпшоты — `JSON` (структура из `payload_json`) и `XLSX` (плоское представление для бухгалтерии).
- Реестры транзакций и выплат — `CSV` (UTF-8, разделитель `;`) и `XLSX`.
- Закрывающие документы — `PDF` с электронной подписью оператора.

## Порядок выгрузки

1. Пользователь с ролью `cfo`, `finance_manager`, `accountant` или `auditor` запрашивает выгрузку через личный кабинет.
2. Запрос фиксируется в `audit_log` с `action='export_requested'`.
3. Система формирует архив и предоставляет ссылку на скачивание со сроком действия 24 часа.
4. После скачивания фиксируется событие `action='export_downloaded'`.

## Закрывающие документы

Закрывающие документы по комиссиям формируются ежемесячно до 5-го числа месяца, следующего за отчётным. Состав:

- Акт выполненных работ по операциям с корпкартами.
- Акт выполненных работ по выплатам.
- УПД (универсальный передаточный документ) за месяц.

Документы доступны для скачивания в личном кабинете в течение 5 лет с даты формирования.

## Ограничения

Глубина выгрузки реестров — не более 13 месяцев в одном запросе. Для более глубоких периодов формируется несколько последовательных запросов. Размер одного архива не должен превышать 500 МБ; при превышении архив автоматически разбивается на части.

## Подтверждение действия

Запрос на выгрузку всегда формирует draft-предложение `suggested_action.kind = 'export_report'` в ассистенте — с обязательным подтверждением пользователя перед фактическим запуском в личном кабинете.
