# Шаблон годовой финансовой отчётности

Документ задаёт структуру стандартного годового отчёта оператора BaaS-платформы для компании-партнёра. Снэпшот сохраняется в `report_snapshots` с `report_type='annual'`.

## Период и сроки

Период покрывает один календарный год (1 января — 31 декабря). Снэпшот формируется до 15 февраля года, следующего за отчётным, и фиксируется в личном кабинете партнёра.

## Состав отчёта (`payload_json`)

Годовой отчёт включает все поля квартального шаблона (см. `report_quarterly_template`) плюс расширения:

- `quarterly_breakdown` — четыре квартальных снэпшота, агрегированных в одном поле для сравнения сезонности.
- `top_merchants` — топ-50 контрагентов по объёму операций.
- `top_recipients` — топ-50 получателей выплат.
- `tariff_changes` — список переходов между тарифами в течение года и связанные эффекты на комиссии.
- `compliance_summary` — суммарные показатели по reason-кодам отказов и инцидентам комплаенса.
- `audit_trail_summary` — статистика записей в `audit_log` (число запросов, число cross-tenant попыток с `severity='high'`).

## Валюта и курсовые

Базовая валюта — RUB. Для операций в иных валютах используется курс ЦБ РФ на дату операции; в годовом отчёте дополнительно показывается среднегодовой курс и его влияние на агрегаты.

## Подписи и доступ

Годовой отчёт подписывается CFO компании-партнёра в личном кабинете оператора. Подпись фиксируется как событие в `audit_log`. Чтение доступно ролям `cfo`, `finance_manager`, `accountant`. Аудитор получает полный доступ для целей внутренней проверки.

## Срок хранения

Годовой снэпшот хранится в `report_snapshots` бессрочно (с учётом требований законодательства РФ о хранении бухгалтерской документации — не менее 5 лет). Удаление возможно только на основании решения CFO компании-партнёра, с записью в `audit_log`.

## Связь с закрывающими документами

Годовой отчёт сопровождается набором закрывающих документов (акты, счета-фактуры по комиссиям). Регламент выгрузки и состав закрывающих — `report_export_procedure`.
